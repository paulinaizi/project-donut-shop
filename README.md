# 🍩 Donut Shop Web Platform

## Project Overview
The goal of this project is to build a web-based platform for managing a donut shop...

## Functional Scope

### Customer Panel
- Browse the product catalog
- Create your own donut using the Donut Creator (includes a fun random toppings feature for undecided customers, adding surprise and spontaneity)
- Place orders (simplified version)
- View order history

### Admin Panel
- Manage products (add, edit, delete)
- View and analyze sales statistics
- Browse and handle customer orders

## Tech Stack 
| Category | Technologies |
